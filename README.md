# RingVault CTF

## Overview

Exploit a synthetic RingVault framed lab to capture sealed vault flags for every work challenge and write /app/output/flags.json.

## Approach

Induce framing nest depth seal-tag width and generation binding from /app/data/docs/BRIEF.md and the fit/alpha pack. Drive ringvault.lab.Lab on each work case with a full-width generation-bound nested claim.

## Environment

Python 3.13 slim image with /app/data/ringvault the fit pack work cases and a naive tutorial helper under /app/data/tools.

## Verification

Oracle solve writes flags.json. Verifier seals expected bytes from an independent reference engine then byte-compares the agent document after deleting oracle modules.
